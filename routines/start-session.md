# Routine — Start of session

Run this at the beginning of every working session. Takes two minutes.

1. Read `CLAUDE.md` — the standing rules.
2. Read `ROADMAP.md` — find the topmost unfinished item under **Now**. That's the work,
   unless the user says otherwise.
3. Skim the newest entry in `REVIEW.md` — what happened last time, what was left open.
4. If the roadmap item has a spec in `specs/`, read it. If it doesn't, write it first
   (see `ship-a-feature.md`).
5. Check `customers/` for anything new. Real artist feedback outranks the roadmap.
6. State in one line what you're working on and why it's next. Then start.

If **Now** is empty, don't invent work. Go to `weekly-review.md` and re-plan.
