# customers/

One file per tattoo artist we talk to. Named `firstname-studio.md`.

Rules:

- **Record what they said, not what you concluded.** Verbatim quotes are the point.
  "Too many messages" is a summary; "I asked her four times how big and she kept
  saying medium" is evidence.
- Log every conversation in the same file, newest at the top.
- If an artist says something that contradicts the roadmap, that's the most valuable
  thing in this folder. Note it in `REVIEW.md` too.
- No artists talked to yet. Until this folder has real files in it, everything in
  `context/` is a hypothesis.

Copy `_template.md` to start a new one.
