# specs/

One file per feature, written before it's built. Numbered in build order.

A spec here is short on purpose — a page, not a document. It exists to answer "what
exactly are we making and how do we know it's done" before anyone opens an editor.
Copy `_template.md`.

Keep the spec honest after the fact: if the build diverged, update the spec to match
what shipped. A spec that describes code we didn't write is worse than no spec.
